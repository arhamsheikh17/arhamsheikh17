I'm a Data Engineer with a background in software development and a focus on cloud data platforms.

## Featured Projects

### [YouTube Trending Data Pipeline](https://github.com/arhamsheikh17/youtube-trending-data-pipeline)

An AWS pipeline that collects YouTube trending data across **10 regions** and organizes it into **Bronze, Silver, and Gold layers**. Includes data quality checks and analytical tables for trending videos, channels, and categories.

**Stack:** Python · PySpark · S3 · Glue · Lambda · Step Functions · Athena

### [Snowflake Data Warehousing & Slowly Changing Dimensions](https://github.com/arhamsheikh17/scd-data-warehousing-with-snowflake)

A data warehousing project exploring **change data capture and SCD Type 1 and Type 2**. Uses automated ingestion and Snowflake Streams and Tasks to manage current records and historical changes.

**Stack:** Python · SQL · Snowflake · Snowpipe · Apache NiFi · S3 · Docker

### [E-commerce Data Pipeline](https://github.com/arhamsheikh17/ecommerce-airflow-data-pipeline)

An e-commerce data pipeline combining **Amazon Kinesis, managed Apache Airflow, and Snowflake** for data ingestion and workflow orchestration.

**Stack:** AWS · Amazon Kinesis · Apache Airflow / MWAA · Snowflake

### [AWS ETL Pipeline with Redshift](https://github.com/arhamsheikh17/etl-with-redshift-glue-stepfunction)

An automated workflow that processes CSV data with **AWS Glue**, loads it into **Amazon Redshift**, and prepares outputs for **QuickSight**. Includes orchestration and failure notifications.

**Stack:** Python · SQL · S3 · Glue · Redshift · Step Functions · SNS · QuickSight
